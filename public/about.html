// how it works

// stack
language: Rust
protocol: HTTP/1.1 over TCP
concurrency: thread pool — 4 workers
dependencies: none — std only
port: 8080
// request lifecycle
1. TcpListener accepts a connection on port 8080
2. Connection is sent to a worker thread via channel
3. Worker parses the HTTP request line
4. Router matches the path to a file in /public
5. File is read and sent back as an HTTP response
6. Response time is logged to the terminal
